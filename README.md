## 时代使命：人人都是管理者

历史上，大多数人一辈子没有管理过任何人——管理是少数人的职业技能。AI 时代，这一切改变了：**每个人都需要管理智能体**。管理学不再是领导者的选修课，而是每个人的基础素养。

这套库的双重使命：**学会管理下属，也是学会管理 AI 智能体**。目标对齐、任务拆解、过程验收、反馈迭代、分工协作——五个核心管理动作对人和对 AI 完全同构（见 `references/20-AI时代管理映射.md`）。从没管过人？先管 AI：这是零成本的管理实训场。

## 双入口：两种问法，同一个系统

**入口 A · 情景匹配**——你说得出具体问题（"团队里有人……"）：

1. 还原情景 → 2. **复合匹配** 70 条中的 2-4 条（真实情景从来不是单条）→ 3. 定性（能力/意愿/结构）→ 4. 行动卡 → 5. **攻防三回合推演** → 6. 挂案例
   - 复合匹配示例："老员工抱怨任务重、还总摸鱼" ＝ 第 21 条＋第 10 条＋第 26 条

**入口 B · 环境评估**——你说不清问题，只能描述处境（"我刚接手一个烂摊子""团队死气沉沉"）：

1. **五维评估**（结构/权力/人员/矛盾/窗口期）→ 2. **处境命名**（权力真空期、礼貌的沉默、救火队长陷阱、能人依赖症……命名即路由）→ 3. 核心矛盾＋你的杠杆 → 4. **30/60/90 天路径**
   - 示范输出："先说结论：你的团队不是没有问题，是问题不再上报了——沉默不是和谐，是节能。"（命名：礼貌的沉默）

两个入口最终都落到 70 条——评估只做翻译与排序，方法永远出自 70 条。

## 攻防三回合推演（本库的博弈层）

每个方法都推演**完整博弈树**：出招／接招为一回合，推满三回合，每一手接对方上一手应对的破绽（连环原则），落到均衡点。示例（第 10 条·不定时抽查）：

> 出招：不定期查交付 → 接招：表演式忙碌 → 连环：改查外部指标（表演只对内有效）→ 接招：求下游给好评 → 连环：指标推到终端结果（伪造成本超过真干活）→ 接招：回归真实。**均衡点**：抽查通过抬高伪造成本，让"真实"成为最便宜的选择，然后功成身退。

贯穿其中的**照妖镜原理**：经得起识破的方法才是好方法——推演到底会发现，透明化、制度化的招识破了照样赢。一句话：**管理博弈的纳什均衡，建立在双方都能看见棋盘的地方。**

## 我们信什么

- **控制让人服从，成就让人追随。** 这套库教的是成就人的能力，不是控制人的技巧。
- **管理学就是发现价值**（德鲁克思想的通行提炼）：70 个所谓"问题"，其实是 70 种放错位置的价值——爱攀比＝竞争意识，"刺头"＝有主见，"老油条"＝组织记忆。库内附"发现价值之眼"对照表：先发现价值，再使用方法。
- **方法之前，先立边界**：五条价值观边界（换岗≠逼退、抽查≠监控、规矩当众立指导私下给、不靠告密优化团队、有些情况体面分开比硬改造更慈悲）＋自我检查四问。这套库教管理，不教伤害。
- **古今中外，一个配比**：700 个案例国内国外大致对半——华为胖东来 ↔ 丰田桥水，史记左传 ↔ 谷歌奈飞，德鲁克 ↔ 资治通鉴。

## 行动卡长什么样

问："我团队有个老员工，活儿能干，但天天在私下吐槽团队，怎么管？"

```
【情景】资深员工，产出稳定，私下负面言论多
【匹配】第32条（背后吐槽）＋第26条（老员工价值感缺失是根因）——吐槽是症状，价值感是病灶
【定性】意愿（归属感），不是能力
【首选方法】库七·第32条：单独约谈，先听后导
【配套方法】第26条：安排新人向他请教
【落地三步】本周1:1只听不辩→下月给"被需要"的位置→观察小群活跃度
【话术】"听说你有些想法，今天没别人，你直说——说错了我当没听见，说对了我改。"
【节奏】两周见温度，一月见行为
【注意】别问"谁告诉我的"——保护渠道比知道答案更重要
【攻防推演】出招约谈→接招官话/告状→连环改问具体问题（提案出口）→接招输出真实观点→连环好建议公开落地署名→接招下次带清单来。均衡点：吐槽能量改道——从背后流向桌面
【案例】【企业】华为心声社区【警示】茶颜悦色2021【历史】狄仁杰不知谮者
```

## 九种管理思维

| 库 | 思维 | 一句话 |
|---|---|---|
| 一 立规矩 | 制度思维 | 好的规则替你说难说的话 |
| 二 留痕迹 | 透明思维 | 信任建立在可见之上 |
| 三 改结构 | 系统思维 | 人没变，位置变了，结果就变了 |
| 四 事实教育 | 成长思维 | 把挫折变成可控的成长课 |
| 五 控节奏 | 拆解思维 | 大目标变成小台阶，人人都走得动 |
| 六 设赛道 | 激励思维 | 让人自己想赢 |
| 七 给反馈 | 安全感思维 | 心理安全是高绩效的地基 |
| 八 汇报表达 | 结构化思维 | 会表达，是想得清的证明 |
| 九 工作方法 | 过程思维 | 把个人的聪明变成团队的流程 |
