## 这是什么

网上流传的"驭人术 70 条"（爱攀比→考核透明、老油条→调换岗位、完美主义→设定最低可交付标准……）是一份很好的**口诀清单**，也是一份没法用的清单：背了口诀，遇到活人还是不会开方。

这个仓库把它升级成一套完整的**诊断-开方系统**，做成 Agent Skill，装进 Claude Code / Codex / ZCode 等任何支持 Agent Skills 的工具，你描述一个带人难题，它输出一张开方卡：定性 → 药方 → 落地三步 → 可照抄的话术 → 剂量 → 忌口 → 案例。

一句话：**市面上的驭人术教你背口诀，这套库教你开药方。**

## 案例长什么样

随手摘三条：

- **第 30 条 盲目接需求** →【史记】李牧守雁门，匈奴每次来犯都"急入收保，不敢战"，被骂懦夫、被替换——新将岁余出战，数败。李牧复到，依旧不战，厚养士卒，等"边士日得赏赐而不用，皆愿一战"，一战灭匈奴十余万骑。被骂的那几年，正是资源评估期。
- **第 56 条 嫉妒** →【史记】群臣争功人心浮动，张良献策：先封刘邦最恨的雍齿。"雍齿尚为侯，我属无患矣"——封完最恨的人，所有人的嫉妒瞬间熄火。
- **第 1 条 爱攀比** →【西游】蟠桃盛会天下有头有脸的神仙都请了，唯独没请齐天大圣——大闹天宫这场改写三界秩序的祸事，起因是一张请柬名单。激励体系的暗雷从来不在奖多奖少，在"谁被漏了"。

```bash
git clone https://github.com/forrestneo/yurenshu.git

# Claude Code
cp -r yurenshu/skills/yurenshu ~/.claude/skills/

# ZCode
cp -r yurenshu/skills/yurenshu ~/.zcode/skills/

# Codex 及其他支持 Agent Skills 的工具同理：把 skills/yurenshu 放进技能目录
```

装好后直接提问，比如：

> 我团队有个老员工，活儿能干，但天天在私下吐槽团队，怎么管？

Skill 会按开方卡输出：

```
【定性】不为（意愿+情绪）——能力没问题，归属感出了问题
【主方】柜七·第 32 条：单独约谈，及时纠正负面想法
【辅方】第 44 条（正向反馈）、第 26 条（安排新人向他请教）
【落地三步】
  1. 本周内 1:1，只听不辩，先让他把话说完
  2. 下月给他一个"被需要"的位置：让新人跟他学
  3. 观察他在小群的活跃度，降温即有效
【话术】"听说你有些想法，今天没别人，你直说——说错了我当没听见，说对了我改。"
【剂量】两周见温度，一月见行为；一个月无效，转入价值观评估
【忌口】别问"谁告诉我的"——出卖线人等于宣告一对一制度作废
【案例】【企业】华为心声社区（"罗马广场"）…【反例】茶颜悦色 2021 内部群骂战…
```

## 红线声明（本库与"职场 PUA 教程"的区别）

这套库教驭人，不教驯人。库内设五条硬红线，每条都有真实"尸检报告"：

1. **换岗 ≠ 逼退**——日本"追い出し部屋"判例摆在那里
2. **抽查 ≠ 监控**——查交付叫管理，查屏幕叫侵犯
3. **当众立规矩 ≠ 当众羞辱**——规矩对事，批评对人（且在私下）
4. **拆团 ≠ 养告密**——打散靠编制调整，永不靠匿名举报
5. **不治之症别用药**——价值观冲突、诚信问题、能力天花板，换人比改造快，也慈悲

拿不准的时候过一遍 **PUA 分界四问**：这招让他更强了还是更怕我了？规则他事先知道吗？他有申诉出口吗？我敢把这招讲给全团队听吗？——四问有一问不过，那不是驭人术，是驯人术。

另附中国职场语境的劳动法速查（调岗调薪、罚款权、绩效辞退、监控边界），管理动作先过合法线。

- **带团队的人**：遇到具体的带人难题，查策开方

- **研究组织的人**：700 条案例按九柜编目，是一份跨古今中外的管理案例索引
