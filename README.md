## 时代使命：人人都是管理者

历史上，大多数人一辈子没有管理过任何人——管理是少数人的职业技能。AI 时代，这一切改变了：**每个人都需要管理智能体**。管理学不再是领导者的选修课，而是每个人的基础素养。

这套库的双重使命：**学会管理下属，也是学会管理 AI 智能体**。目标对齐、任务拆解、过程验收、反馈迭代、分工协作——五个核心管理动作对人和对 AI 完全同构（见 `references/20-AI时代管理映射.md` 的 20 条映射表：书面确认需求 → prompt 三件套，化整为零 → 任务分解，抛砖引玉 → few-shot 示例，闻过则喜 → 鼓励 AI 表达不确定性……）。从没管过人？先管 AI：这是零成本的管理实训场。

## 这是什么

网上流传的"驭人术 70 条"（爱攀比→考核透明、老油条→调换岗位、完美主义→设定最低可交付标准……）是一份很好的口诀清单，也是一份没法用的清单：背了口诀，遇到活人还是不会处理。

这个仓库把它升级成一套**培养管理者管理思维的正向系统**，做成 Agent Skill，装进 Claude Code / Codex / ZCode 等任何支持 Agent Skills 的工具。你描述一个带人难题，它输出一张行动卡：思维定性 → 首选方法 → 落地三步 → 可照抄的话术 → 节奏 → 注意事项 → 案例。

一句话：**市面上的管理口诀教你背句子，这套库帮你建立管理思维。**

这套库的价值主张源自德鲁克：**管理学就是发现价值**——70 个所谓“问题”，其实是 70 种放错位置的价值（爱攀比＝竞争意识，“刺头”＝有主见，“老油条”＝组织记忆）。库内附“发现价值之眼”对照表：先发现价值，再使用方法。

## 我们信什么

- **控制让人服从，成就让人追随。** 这套库教的是成就人的能力，不是控制人的技巧。
- **好的管理，是让平凡的人做出不平凡的事**（德鲁克）——每一条方法都在回答：怎么让这个人在这件事上变得更好。
- **方法之前，先立边界**：五条价值观边界（换岗≠逼退、抽查≠监控、规矩当众立指导私下给、不靠告密优化团队、有些情况体面分开比硬改造更慈悲）写在所有方法前面。拿不准时过一遍自我检查四问——这套库教管理，不教伤害。
- **古今中外，一个配比**：700 个案例国内国外大致对半——华为胖东来 ↔ 丰田桥水，史记左传 ↔ 谷歌奈飞，德鲁克 ↔ 资治通鉴。

## 案例长什么样

随手摘三条：

- **第 30 条 盲目接下需求** →【史记】李牧守雁门，匈奴每次来犯都"急入收保，不敢战"，被骂懦夫、被替换——新将岁余出战，数败。李牧复到，依旧不战，厚养士卒，等"边士日得赏赐而不用，皆愿一战"，一战灭匈奴十余万骑。被骂的那几年，正是资源评估期。
- **第 56 条 嫉妒别人出成绩** →【史记】群臣争功人心浮动，张良献策：先封刘邦最恨的雍齿。"雍齿尚为侯，我属无患矣"——封完最恨的人，所有人的嫉妒瞬间熄火：嫉妒不是被安抚的，是被重新锚定的。
- **第 1 条 爱攀比** →【西游】蟠桃盛会天下有头有脸的神仙都请了，唯独没请齐天大圣——大闹天宫这场风波，起因是一张请柬名单。激励体系的暗雷从来不在奖多奖少，在"谁被漏了"。

## 快速开始

```bash
git clone https://github.com/forrestneo/yurenshu.git

# Claude Code
cp -r yurenshu/skills/yurenshu ~/.claude/skills/

# ZCode
cp -r yurenshu/skills/yurenshu ~/.zcode/skills/

# Codex 及其他支持 Agent Skills 的工具同理：把 skills/yurenshu 放进技能目录
```

装好后直接提问（中英文都可以），比如：

> 我团队有个老员工，活儿能干，但天天在私下吐槽团队，怎么管？

Skill 会按行动卡输出：定性（意愿与情绪，不是能力）→ 首选方法（第 32 条：单独约谈）→ 落地三步 → 可照抄的话术（"听说你有些想法，今天没别人，你直说——说错了我当没听见，说对了我改。"）→ 节奏（两周见温度，一月见行为）→ 注意（别问"谁告诉我的"——保护沟通渠道比知道答案更重要）→ 案例（华为心声社区的正面对照、茶颜悦色 2021 的警示对照）。

## 九种管理思维

| 方法库 | 管理思维 | 一句话 |
|---|---|---|
| 一 立规矩 | 制度思维 | 好的规则替你说难说的话 |
| 二 留痕迹 | 透明思维 | 信任建立在可见之上 |
| 三 改结构 | 系统思维 | 人没变，位置变了，结果就变了 |
| 四 事实教育 | 成长思维 | 把挫折变成可控的成长课 |
| 五 控节奏 | 拆解思维 | 大目标变成小台阶，人人都走得动 |
| 六 设赛道 | 激励思维 | 让人自己想赢 |
| 七 给反馈 | 安全感思维 | 心理安全是高绩效的地基 |
| 八 汇报表达 | 结构化思维 | 会表达，是想得清的证明 |
| 九 工作方法 | 过程思维 | 把个人的聪明变成团队的流程 |
