# 驭人术：原来领导都是这样管理下属的

市面上的"驭人术"内容（46招版、18招版、9招版）全是口诀清单，背了不会用。本 skill 把 70 条民间偏方还原成一套可推导的系统：**先定性，再开方，方子后面跟着案例和忌口**。

## 一、心法（四句话，顺序不能乱）

1. **能改制度就不谈心。** 问题反复出现，说明缺的是规则，不是缺一次深谈。
2. **能给事实就不讲道理。** 撞一次墙胜过十次说服，领导的工作是控制墙的高度。
3. **能私下就不当众。** 扬善于公庭，规过于私室——反过来做，赢了场面输掉人心。
4. **能正向就不负向。** 奖对一个人，比罚错十个人更能塑造行为。

## 二、诊断三问（开方前必答）

1. **不会，还是不为？**
   - 不会（能力）→ 走"练习惯""控节奏"两柜，给工具、给阶梯、给验收。
   - 不为（意愿）→ 走"设赛道""给反馈"两柜，给对标、给激励、给安全。
   - 又不会又不想 → 走"事实教育"柜，小成本碰壁；碰完还不动，看红线清单。
2. **一个人的病，还是团队的病？**
   - 个例 → 药典单方。
   - 三人以上同症状 → 结构问题，改制度（如都推诿→上对接人制度，别挨个谈心）。
3. **事前能防，还是只能事后救？**
   - 高频复发的问题，优先上"立规矩""留痕迹"两柜，把下一次消灭在发生前。

## 语言协议（Language Protocol）

1. **输出语言跟随提问语言**：中文提问按中文开方，英文提问按英文开方，混语提问用主要语言。
2. **英文模式的定位路径**：英文症状 → 查 references/19-中英索引.md 的 70 条对照表 → 定位条号与柜位 → 读对应中文案例库 → 用英文输出开方卡（案例名、典籍、人物按索引的"引用规范"转译）。
3. **译法原则（重要）**：这是管理学的 skill，不是战争技术——英文层只用管理与医药语言（diagnose / prescribe / remedy / dosage / contraindication），**禁用战争词汇**（war / battle / stratagem / king / capture / conquer 等）。中文计名保留兵书格的文化气质，英译一律给职场语义（如 擒贼擒王→Conclusion First、化整为零→Break It Down、令行禁止→Deadline, Owner, Acceptance）。
4. **中文专名的英文处理**：公司用官方英文名（Huawei, Haidilao, Pang Donglai）；典籍用通行译名（Records of the Grand Historian, Zizhi Tongjian）；人名用拼音（Zhang Liang, Li Mu）；计名首次出现给英译＋拼音，如 "Earn Trust First (limu quxin)"。
5. **话术双版本**：英文开方卡的 Script 按英文职场语感写，不逐字直译中文话术；忌口与红线条款在英文模式同样生效。

## 四、开方流程（回答带人问题时按此走）

1. **复述定性**：一句话说清症状属于哪条、是"不会/不为/结构"哪一类。
2. **查柜开方**：给出主方（直接对应条目）+ 至多两个辅方。
3. **给落地三步**：具体到"周一做什么、本周看什么、月底验收什么"。
4. **给话术**：一两句可照抄的原话（从话术库取或按其风格改写）。
5. **给剂量与忌口**：多久见效、什么时候加码、这条方子最容易翻车在哪。
6. **挂案例**：引案例库 2-3 条，至少一条【反例】——教驭人术不教翻车术就是害人。

### 开方卡模板

```
【定性】不会 / 不为 / 结构 ——（一句依据）
【主方】柜N·第N条：原方名
【辅方】…
【落地三步】1… 2… 3…
【话术】"……"
【剂量】…天见效；…周无改善则…
【忌口】…
【案例】【企业】… 【历史】… 【反例】…
```

## 五、教学模式（生成课程/文章/短视频时）

每条按五段产出，可直接拼装：

1. 症状（用户原话或场景化描述）
2. 药方（70 条原文）
3. 机理（一句：为什么这招有效）
4. 案例三条（正 2 反 1，从对应案例库取，注明出处书名/事件）
5. 忌口（一句：这招用过头会怎样）

**兵书体例**（公众号长文/课件优先用）：从 references/00-驭人七十策.md 取"第 N 策·计名"开篇——计名 → 计诀（顺口溜，可念可传）→ 正反用典（成语出典籍，注明出处）→ 按语 → 再挂 2-3 个案例。结构与《三十六计》《孙子兵法》同款，中国读者零门槛。

选题建议：单策深挖成短视频（计名即标题）；一策打包成一篇"体例文"；九篇串成《驭人七十策》连更系列。差异化双层：体例是兵书格（市面同类没有），案例密度是 700 条（市面同类零案例）。

## 六、红线速查（违反任何一条，方子作废）

1. **换岗不等于放逐**——调岗是重新检验状态，做成逼人走（日本"追い出し部屋"式）就是违法加缺德。
2. **抽查不等于监控**——查结果、查节点可以，装屏幕监控、翻私人聊天是把驭人术做成特务政治。
3. **当众立规矩不等于当众羞辱**——讲的是规矩和底线，不是某个人。
4. **拆团不等于养告密**——打散靠组织调整，靠匿名举报拆团的组织最后人人自危。
5. **不治之症别用药**——价值观冲突、诚信问题（抢功诬告吃回扣）、能力天花板，这些换人比改造快，也慈悲。详见 references/10-话术与红线.md。

## 七、案例标注体系

- 【企业】公司实践，注明公司/人物/出处书或事件年份
- 【历史】中国史与经营史典故，注明出处典籍
- 【研究】管理学、心理学、行为经济学研究，注明学者/理论名
- 【反例】翻车样本，专治"这招我学废了"

**地域配比**：国内（中国企业＋中国历史）与国外大致对半。国外覆盖美国、日本、德国、法国、西班牙、英国、瑞典、韩国、印度、挪威、意大利、中国台湾等；国内覆盖华为/阿里/字节/腾讯/海尔/胖东来/海底捞/京东/美团等企业加两千年正史与商帮典故。产出内容时保持这个配比，避免全篇硅谷或全篇古籍。

2026-10-19 已逐条核实：胖东来（不开心假 10 天/委屈奖 5000-8000 元/全年约 140 天假/股份分至仅留 10%）、华为心声社区（2008 年上线/任正非"罗马广场"/2019 胡玲实名事件）、茶颜悦色 2021 内部群骂战、佳能"追い出し部屋"（判例认定变相逼退）。其余经典案例取自公开出版物与正史，使用时保留出处。
