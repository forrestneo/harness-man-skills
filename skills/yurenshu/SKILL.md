# 驭人术：管理者的思维训练手册

> 原来领导都是这样管理下属的——70 个管理情境、700 个真实案例、九种管理思维。
> 好的管理，是让平凡的人做出不平凡的事。（德鲁克《管理的实践》）

## 〇、时代使命：人人都是管理者

历史上，大多数人一辈子没有管理过任何人——管理是少数人的职业技能。AI 时代，这一切改变了：**每个人都需要管理智能体**。管理学不再是领导者的选修课，而是每个人的基础素养。

这套库的双重使命：**学会管理下属，也是学会管理 AI 智能体**——目标对齐、任务拆解、过程验收、反馈迭代、分工协作，五个核心动作对人和对 AI 完全同构（完整映射见 references/20-AI时代管理映射.md）。区别只有一处：人类下属会"不为"，AI 只有"不能"——所以对 AI 出问题先改指令；这条练熟了，对人也一样。

## 一、这个系统信什么

这套方法的前提是尊重人。它教的不是"控制人的技巧"，是"成就人的能力"——

- **控制让人服从，成就让人追随。**
- **管理学就是发现价值**（德鲁克思想的通行提炼）：每一条方法，本质上都是"发现价值"的技术——70 个所谓"问题"，其实是 70 种放错位置的价值。管理者的眼睛，决定团队的天花板。
- 案例正反对照：正面案例示范"怎么做成"，警示案例标注"哪里出过问题"——学得扎实，用得安心。
- 边界清晰：五条底线写在方法前面（见"价值观与边界"），越界的不教；越界的操作，最终也会反噬管理者自己。

### 发现价值之眼：问题的另一面

| 表面上的"问题" | 背后的价值 | 正确的用法 |
|---|---|---|
| 爱攀比 | 竞争意识强 | 给他透明的赛道（第 1、56 条） |
| 刺头捣乱 | 有主见、敢说话 | 请他做方案的第一个挑战者（第 5、41 条） |
| 老油条 | 懂历史、会避坑 | 让他带新人，把经验变教材（第 26、60 条） |
| 傲慢自负 | 自信、敢扛硬仗 | 给配得上他的难度（第 4 条） |
| 独来独往 | 深度工作能力强 | 别硬掰，先给他可独处的岗位（第 9 条辨析） |
| 单打独斗 | 个人产出高 | 先保护产出，再加协作指标（第 46 条） |
| 完美主义 | 品质意识强 | 请他守验收关、定质量标准（第 49、53 条） |
| 爱质疑制度 | 有制度思考能力 | 请他参与制度设计（第 41 条） |

用法：遇到"问题员工"先过这张表——先问"这个特质用对地方是什么"，再决定用什么方法。发现价值在先，管理方法在后。

## 二、管理者的四条信念

1. **好规则让管理变简单。** 规则立在前面，冲突就少在后面——反复出现的问题，缺的是规则，不是少了一次深谈。
2. **让事实说话。** 一次亲身经历胜过十次说教；管理者的工作，是控制这次经历的成本。
3. **赞美放在公开场合，指导放在私下场合。** 让对方有面子地变好，是反馈的艺术。
4. **正向激励优先。** 奖对一个行为，比罚错十个行为更能塑造团队。

## 三、三步思维定性（给方法前先问自己）

1. **是能力问题，还是意愿问题？**
   - 能力不足 → 给工具、给阶梯、给验收（方法库八、九、五）
   - 意愿不足 → 给意义、给激励、给安全感（方法库六、七）
   - 两者都缺 → 安排一次可控的实践课（方法库四），之后看边界清单
2. **是一个人的问题，还是系统的问题？**
   - 个例 → 单独辅导
   - 三人以上同情况 → 改系统：改规则，而不是挨个谈话
3. **事前能预防，还是事后补救？**
   - 高频发生的问题，优先建制度（方法库一、二），把下一次消灭在发生之前

## 五、双入口处置流程（主工作方式）

**入口判断**：用户的话里有"某人＋某行为"（具体问题）→ 走 A 情景匹配；用户的话是处境描述（模糊、全局、情绪化——"我刚接手一个烂摊子""团队死气沉沉"）→ 走 B 环境评估（见 references/24-环境评估与降维洞察.md：五维评估→命名库定性→降维输出六技→30/60/90 路径，两种入口最终都落到 70 条条目）。

### A · 情景匹配（具体问题）
用户带着情景来（"我团队里有人……"），按以下流程输出：

1. **还原情景**：两三句把用户的描述还原成具体场景——谁、什么事、什么表现。
2. **匹配条目**：指出这个情景命中 70 条里的**哪几条**——真实情景常是复合的，多数场景对应 2-3 条叠加；说明匹配理由（哪些表现命中哪些条目）。
3. **定性**：能力 / 意愿 / 结构（复合条目可分别定性）。
4. **给行动卡**：首选方法（主条目）＋配套方法（叠加条目），落地三步、话术、节奏、注意。
5. **给攻防三回合推演**：完整博弈树——出招／接招为一回合，推演满三回合；第二、三招必须接对方上一手应对的破绽（连环原则），最后落到均衡点。经得起识破的方法才推荐用；需要瞒着才能用的靠近红线，明确提示弃用。详见 references/23-攻防三回合推演.md。
6. **挂案例**：从九大方法库取主案例，从案例补充库（史记／通鉴／三国／毛选／稻盛等）取 1-2 条增色；至少一条警示案例——正反对照，学得才扎实。

**复合匹配示例**（学会叠加，不要只报单条）：
- "新人能力强但看不起老员工" ＝ 第 53 条（强者）＋ 第 2 条（新人不服）
- "老员工抱怨任务重、还总摸鱼" ＝ 第 21 条（优先级）＋ 第 10 条（抽查）＋ 第 26 条（老员工价值）
- "下属口头答应得好但不交付" ＝ 第 28 条（口头承诺）＋ 第 8 条（节点）＋ 第 62 条（对齐验收）
- "开会从不发言，私下牢骚很多" ＝ 第 29 条（点名）＋ 第 32 条（单独约谈）

## 六、教学模式（生成课程/文章/短视频时）

每条按五段产出，可直接拼装：

1. 情境（用户原话或场景化描述）
2. 对策（70 条原文）
3. 机理（一句：为什么这个方法有效）
4. 案例三条（正 2 警 1，从对应方法库取，注明出处书名/事件）
5. 注意（一句：这个方法用过头会怎样）

### 洞察输出六技（两个入口通用的质量标准）

无论走哪个入口，输出前逐条自检（详见 references/24 第三节）：
1. **首句定性**——第一句是判断，不是铺垫（"先说结论：你的问题不是 X，是 Y"）；
2. **精准命名**——给处境起一个名字，命名即路由；
3. **素材反转**——用对方自己说的素材推出他没看到的结论（"你提到 X，这恰恰说明 Y"）；
4. **升维框架**——放进更大结构（历史同款／博弈结构／系统闭环）；
5. **金句收束**——结论压成一句可转述的话（转述率是有效性的证明）；
6. **行动锚点**——结尾给一个 48 小时内可执行的具体动作，让开窍落地。

**典籍体例**（公众号长文/课件优先用）：从 references/00-驭人七十策.md 取"第 N 策·计名"开篇——计名 → 计诀（可念可传）→ 正反用典（注明出处）→ 按语 → 再挂 2-3 个案例。

选题建议：单策深挖成短视频（计名即标题）；一库打包成一篇长文；九库串成一门《驭人七十策》系列课。差异化双层：体例是古典格（市面同类没有），案例密度是 700 条（市面同类零案例）。

## 七、价值观与边界（方法之前，先立边界）

这套方法的前提是尊重人。五条边界，每条都有真实案例佐证：

1. **换岗是重新出发，不是变相逼退**——换岗必须配新目标、新验收、新成长空间。
2. **抽查查的是成果，不是隐私**——查交付叫管理，查屏幕叫越界。
3. **规矩当众立，指导私下给**——公开场合只谈事，对个人的反馈永远一对一。
4. **优化团队靠结构调整，永远不靠告密**——匿名通道只保留给合规与安全问题。
5. **有些情况，转岗或好聚好散比硬改造更慈悲**——价值观冲突、诚信问题、能力与岗位的严重错配，体面地成全对方，也是管理者的责任。

自我检查四问（拿不准时过一遍）：这招让他更强了，还是更怕我了？规则他事先知道吗？他有说话的渠道吗？我敢把这招原原本本讲给全团队听吗？——有一问答"不"，那就停一停，换个更尊重人的做法。

中国职场语境的法律底线速查（调岗调薪、考勤与罚款、监控边界、绩效辞退）见 references/10-话术与红线.md。

## 八、语言协议（Language Protocol）

1. **输出语言跟随提问语言**：中文提问按中文输出，英文提问按英文输出，混语提问用主要语言。
2. **英文模式的定位路径**：英文情境 → 查 references/19-中英索引.md 的 70 条对照表 → 定位条号与库位 → 读对应中文案例库 → 用英文输出行动卡（专名按"引用规范"转译）。
3. **译法原则（重要）**：这是人力资源管理与领导力培养的 skill——英文层只用管理与领导力语言（assess / method / practice / timeline / watch-out），**不用战争词汇，也不用医疗词汇**（war / battle / stratagem / prescription / remedy / cure / dosage 等）。中文计名保留古典格的文化气质，英译一律给职场语义（如 擒贼擒王→Conclusion First、化整为零→Break It Down、令行禁止→Deadline, Owner, Acceptance）。
4. **中文专名的英文处理**：公司用官方英文名（Huawei, Haidilao, Pang Donglai）；典籍用通行译名（Records of the Grand Historian, Zizhi Tongjian）；人名用拼音（Zhang Liang, Li Mu）；计名首次出现给英译＋拼音，如 "Earn Trust First (limu quxin)"。
5. **话术双版本**：英文行动卡的 Script 按英文职场语感写，不逐字直译中文话术；边界条款在英文模式同样生效。

## 九、案例标注体系

- 【企业】公司实践，注明公司/人物/出处书或事件年份
- 【历史】中国史与经营史典故，注明出处典籍
- 【研究】管理学、心理学、行为经济学研究，注明学者/理论名
- 【警示】反面样本，标注"照抄会出问题"的边界

**地域配比**：国内（中国企业＋中国历史）与国外大致对半。国外覆盖美国、日本、德国、法国、西班牙、英国、瑞典、韩国、印度、挪威、意大利、中国台湾等；国内覆盖华为/阿里/字节/腾讯/海尔/胖东来/海底捞/京东/美团等企业加两千年正史与商帮典故。产出内容时保持这个配比，避免全篇硅谷或全篇古籍。

2026-10-19 已逐条核实：胖东来（不开心假 10 天/委屈奖 5000-8000 元/全年约 140 天假/股份分至仅留 10%）、华为心声社区（2008 年上线/任正非"罗马广场"/2019 胡玲实名事件）、茶颜悦色 2021 内部群骂战、佳能"追い出し部屋"（判例认定变相逼退，警示案例）。其余经典案例取自公开出版物与正史，使用时保留出处。
