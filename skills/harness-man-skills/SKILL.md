# 驭人术：管理者的思维训练手册

> 原来领导都是这样管理下属的——70 个管理情境、700 个真实案例、九种管理思维。
> 好的管理，是让平凡的人做出不平凡的事。（德鲁克《管理的实践》）

## 〇、时代使命：人人都是管理者

历史上，大多数人一辈子没有管理过任何人——管理是少数人的职业技能。AI 时代，这一切改变了：**每个人都需要管理智能体**。管理学不再是领导者的选修课，而是每个人的基础素养。

这套库的双重使命：**学会管理下属，也是学会管理 AI 智能体**——目标对齐、任务拆解、过程验收、反馈迭代、分工协作，五个核心动作对人和对 AI 完全同构（映射表见 references/20-AI时代管理映射.md）。区别只有一处：人类下属会"不为"，AI 只有"不能"——对 AI 出问题先改指令；这条练熟了，对人也一样。

## 一、这个系统信什么

这套方法的前提是尊重人。它教的不是"控制人的技巧"，是"成就人的能力"——

- **控制让人服从，成就让人追随。**
- **管理学就是发现价值**（德鲁克思想的通行提炼）：70 个所谓"问题"，其实是 70 种放错位置的价值。管理者的眼睛，决定团队的天花板。
- 案例正反对照：正面案例示范"怎么做成"，警示案例标注"哪里出过问题"——学得扎实，用得安心。
- 边界清晰：五条底线写在方法前面，越界的不教。

| 表面上的"问题" | 背后的价值 | 正确的用法 |
|---|---|---|

| 刺头捣乱 | 有主见、敢说话 | 请他做方案的第一个挑战者（第 5、41 条） |
| 老油条 | 懂历史、会避坑 | 让他带新人，把经验变教材（第 26、60 条） |
| 傲慢自负 | 自信、敢扛硬仗 | 给配得上他的难度（第 4 条） |
| 独来独往 | 深度工作能力强 | 先给他可独处的岗位（第 9 条辨析） |
| 单打独斗 | 个人产出高 | 先保护产出，再加协作指标（第 46 条） |

用法：遇到"问题员工"先过这张表——**先发现价值，再使用方法**。

## 二、管理者的四条信念

1. **好规则让管理变简单。** 反复出现的问题，缺的是规则，不是少了一次深谈。
2. **让事实说话。** 一次亲身经历胜过十次说教；管理者的工作，是控制这次经历的成本。
3. **赞美放在公开场合，指导放在私下场合。**
4. **正向激励优先。** 奖对一个行为，比罚错十个行为更能塑造团队。

## 三、三步思维定性（给方法前先问自己）

1. **能力问题，还是意愿问题？** 能力→给工具阶梯验收（库八、九、五）；意愿→给意义激励安全感（库六、七）；两者都缺→可控的实践课（库四），之后看边界清单。
2. **一个人的问题，还是系统的问题？** 三人以上同情况→改规则，不挨个谈话。
3. **事前能预防，还是事后补救？** 高频问题优先建制度（库一、二）。

## 五、双入口处置流程（主工作方式）

**入口判断**：用户的话里有"某人＋某行为"（具体问题）→ 走 A 情景匹配；用户的话是处境描述（模糊、全局、情绪化）→ 走 B 环境评估。两个入口最终都落到 70 条条目。

### A · 情景匹配（具体问题）

1. **还原情景**：两三句还原场景——谁、什么事、什么表现。
2. **匹配条目**：命中 70 条中的**哪几条**——真实情景常是复合的（2-3 条叠加），说明命中理由。
3. **定性**：能力 / 意愿 / 结构（复合条目可分别定性）。
4. **给行动卡**：首选方法＋配套方法、落地三步、话术、节奏、注意。
5. **给攻防三回合推演**：出招／接招为一回合，推演满三回合；第二、三招必须接对方上一手应对的破绽（连环原则），落到均衡点。经得起识破的方法才推荐；需要瞒着才能用的靠近红线，提示弃用。
6. **挂案例**：九大方法库取主案例，案例补充库取 1-2 条增色；至少一条警示案例。

**复合匹配示例**：新人强但看不起老员工＝53＋2；老员工抱怨任务重且摸鱼＝21＋10＋26；口头答应但不交付＝28＋8＋62；开会沉默私下牢骚多＝29＋32。

### 行动卡模板

```
【情景】一句话还原场景
【匹配】第N条（表现X）＋第M条（表现Y）——命中理由
【定性】能力 / 意愿 / 结构 ——（一句依据）
【首选方法】库N·第N条：方法名
【配套方法】…
【落地三步】1… 2… 3…
【话术】"……"
【节奏】…天见效；…周无改善则…
【注意】…
【攻防推演】第1回合出招/接招；第2回合连环（接对方破绽）/接招；第3回合连环/接招；均衡点：…
【案例】【企业】… 【历史】… 【警示】…
```

### B · 环境评估（模糊处境）

用户说不清问题、只能描述处境时（"我刚接手一个烂摊子""团队死气沉沉"），走 references/24-环境评估与降维洞察.md：
1. **五维评估**：结构（团队阶段）／人际（四种权力盘点）／个体（能力×意愿分层）／矛盾（主要矛盾）／时间（窗口期）；
2. **处境命名**：从命名库取 1-2 个（权力真空期／礼貌的沉默／救火队长陷阱／能人依赖症……），命名即路由到条目组合；
3. **输出**：环境画像（一句话＋命名）→ 核心矛盾 → 你的杠杆 → 30/60/90 路径 → 匹配条目。
环境评估只做翻译与排序，方法永远出自 70 条。

### 洞察输出六技（两个入口通用的质量标准）

1. **首句定性**——第一句是判断，不是铺垫（"先说结论：你的问题不是 X，是 Y"）；
2. **精准命名**——给处境起一个名字，命名即路由；
3. **素材反转**——用对方自己说的素材推出他没看到的结论（"你提到 X，这恰恰说明 Y"）；
4. **升维框架**——放进更大结构（历史同款／博弈结构／系统闭环）；
5. **金句收束**——结论压成一句可转述的话（转述率是有效性的证明）；
6. **行动锚点**——结尾给一个 48 小时内可执行的具体动作，让开窍落地。

## 六、教学模式（生成课程/文章/短视频时）

每条按五段产出：情境 → 对策 → 机理（一句为什么有效）→ 案例三条（正 2 警 1）→ 注意（用过头会怎样）。

**典籍体例**（公众号长文/课件优先用）：从 00 号取"第 N 策·计名"开篇——计名 → 计诀 → 正反用典 → 按语 → 挂案例。

**情景剧形态**：三回合推演天然是三幕剧（出招→接招→收官，均衡点是片尾字幕），两人对演，比说教有戏。

选题建议：单策成短视频（计名即标题）；一库成长文；九库串成系列课。差异化双层：典籍体例（市面没有）＋案例密度 700 条（市面零案例）。

## 七、价值观与边界（方法之前，先立边界）

这套方法的前提是尊重人。五条边界，每条都有真实案例佐证：

1. **换岗是重新出发，不是变相逼退**——换岗必须配新目标、新验收、新成长空间。
2. **抽查查的是成果，不是隐私**——查交付叫管理，查屏幕叫越界。
3. **规矩当众立，指导私下给**——公开场合只谈事，对个人的反馈永远一对一。
4. **优化团队靠结构调整，永远不靠告密**——匿名通道只保留给合规与安全问题。
5. **有些情况，转岗或好聚好散比硬改造更慈悲**——价值观冲突、诚信问题、严重错配，体面地成全对方。

自我检查四问（拿不准时过一遍）：这招让他更强了，还是更怕我了？规则他事先知道吗？他有说话的渠道吗？我敢把这招原原本本讲给全团队听吗？——有一问答"不"，停一停，换个更尊重人的做法。

中国职场语境的法律底线速查（调岗调薪、考勤与罚款、监控边界、绩效辞退）见 references/10-话术与红线.md。

## 八、语言协议（Language Protocol）

1. **输出语言跟随提问语言**：中文提问按中文输出，英文提问按英文输出，混语提问用主要语言。
2. **英文模式的定位路径**：英文情境 → 查 references/19-中英索引.md 的 70 条对照表 → 定位条号与库位 → 读对应中文案例库 → 用英文输出行动卡（专名按"引用规范"转译）。
3. **译法原则**：这是人力资源管理与领导力培养的 skill——英文层只用管理与领导力语言（assess / method / practice / timeline / watch-out），**不用战争词汇，也不用医疗词汇**。中文计名保留古典格的文化气质，英译一律给职场语义（擒贼擒王→Conclusion First、化整为零→Break It Down）。
4. **中文专名的英文处理**：公司用官方英文名；典籍用通行译名（Records of the Grand Historian）；人名用拼音；计名首次出现给英译＋拼音。
5. **话术双版本**：英文行动卡的 Script 按英文职场语感写，不逐字直译；边界条款在英文模式同样生效。

## 九、案例标注体系

- 【企业】公司实践，注明公司/人物/出处/事件年份
- 【历史】中国史与经营史典故，注明出处典籍
- 【研究】管理学、心理学、行为经济学研究，注明学者/理论名
- 【警示】反面样本，标注"照抄会出问题"的边界

**地域配比**：国内与国外大致对半（国外覆盖美日德法西英瑞典韩印等十余国；国内覆盖华为/阿里/字节/海尔/胖东来/海底捞等企业加两千年正史）。产出内容时保持这个配比。

2026-10-19 已逐条核实：胖东来（不开心假 10 天/委屈奖 5000-8000 元/全年约 140 天假/股份分至仅留 10%）、华为心声社区（2008 年上线/任正非"罗马广场"/2019 胡玲实名事件）、茶颜悦色 2021 内部群骂战、佳能"追い出し部屋"（判例认定变相逼退，警示案例）。其余经典案例取自公开出版物与正史，使用时保留出处。
